# Interactive tools for Governments and Politics of Europe (PLSC 200N)

Practice tools for PLSC 200N, Governments and Politics of Europe. Each tool works through a historical case or a political science model from the course, alongside that week's readings and lecture.

Start at the contents page, `index.html`, which lists the tools by topic. The site is at https://sonagolder.github.io/european-politics-tools/. Each tool is a single self-contained HTML file. It runs in any current browser on a computer or phone, with no login, installation, or external dependencies, and it stores nothing about its users.

## Tools

| Week | Topic | Tool | File |
|---|---|---|---|
| 1 | Democracy's collapse in interwar Germany | Forming a government in the Weimar Reichstag | `weimar-coalition-builder.html` |
| 1 | Democracy's collapse in interwar Germany | The national Nazi vote, and who voted differently from it | `king-swing-decomposer.html` |
| 3 | Communist parties in postwar Eastern Europe | Choosing your ministries | `postwar-cabinet-bargaining.html` |
| 4 | Collective action and protest | Would you take part? | `collective-action-practice.html` |

## Notes

- Week numbers refer to the Fall 2026 syllabus. Tools are added as the course reaches them.
- Link to the contents page or to any individual tool. A tool's address stays the same when it is updated.
- The tools are designed for practice and self-study. The answers are built into each page, so they are not suited to graded work.
